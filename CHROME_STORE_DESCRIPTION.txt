================================================================================
AI KNOWLEDGE ASSISTANT — CHROME WEB STORE DESCRIPTION & PRIVACY JUSTIFICATIONS
================================================================================

AI Knowledge Assistant is a local-first Chrome extension for capturing highlights,
taking notes, and getting real-time AI summaries without leaving the webpage.
Powered by fast multi-model AI routing with automatic failover and Streamdown
Markdown rendering — no API keys or complex flags required. Optional Convex cloud
sync keeps your highlights and notes synchronized across devices when you choose
Sync or Cloud AI privacy modes.

--------------------------------------------------------------------------------
KEY FEATURES
--------------------------------------------------------------------------------

★ SELECTION TOOLTIP & IN-PAGE MODAL (SHADOW DOM)
• Select text to Save, Summarize, Explain, or Summarize Page.
• In-page Shadow DOM modal displays real-time streaming AI answers with formatted
  HTML Markdown rendering (headings, bold text, code blocks, lists, blockquotes).
• Background service worker handles all AI routing — developer API keys never
  touch webpage content scripts.

★ STREAMDOWN MARKDOWN RENDERING
• Powered by Streamdown for ultra-fast, beautifully rendered Markdown output
  across summaries, rewrites, and flashcards.

★ SIDE PANEL DASHBOARD
• Highlights View: Searchable list with favicons, saved dates, delete, and pagination (10 per page).
• Notes View: Markdown note editor with tags, pin/favorite, AI actions (Summarize, Rewrite, Flashcards), and pagination (10 per page).
• AI Timeline View: Searchable event history with latency metadata, Streamdown rendering, and pagination (10 per page).
• Workspaces: Work, Personal, Coding, Research, and Study.
• Theme & Toggles: Light / Dark / System sync themes with feature toggles for Keywords Tile, Sticky Notes, and Tooltip Buttons.

★ SINGLE-TAP 👍 LIKE PERSONALIZATION
• Train AI tone and interest preferences with a single 👍 Like button on any AI output without clobbering base settings.
• Custom AI Tone (Neutral, Friendly, Professional) & Style (Concise, Detailed, Bullets) preferences.

★ MULTI-MODEL AI ENGINE
• Fast multi-model AI with automatic failover if a model is slow or unavailable.
• Real-time streaming responses with local LRU caching and zero user key setup.

★ LOCAL-FIRST & PRIVACY MODES
• IndexedDB-first architecture — highlights and notes work offline instantly.
• Flexible Privacy Modes: Private (Local only) · Sync (Convex sync) · Cloud AI (Sync + Cloud AI preferences).
• Session tokens securely stored in chrome.storage.local.

--------------------------------------------------------------------------------
HOW TO USE
--------------------------------------------------------------------------------

1. Install the extension and open the side panel dashboard from the toolbar icon.
2. (Optional) Sign in under Settings and select your preferred Privacy Mode.
3. Select text on any webpage → Save Highlight or run AI Summary (no API key to paste).
4. Enjoy formatted Markdown responses, manage notes, and browse paginated AI history.

--------------------------------------------------------------------------------
PRIVACY
--------------------------------------------------------------------------------

• Private mode never syncs content to Convex.
• Cloud AI requests send only the prompt text needed to execute the selected AI action.
• Full details available in PRIVACY_POLICY.md.

Version 2.0.1 (Manifest V3)


================================================================================
CHROME WEB STORE PRIVACY PRACTICES — PERMISSION JUSTIFICATIONS
================================================================================
(Copy and paste these exact justifications into the Developer Console -> Privacy tab)

1. Justification for 'alarms':
--------------------------------------------------------------------------------
The 'alarms' permission is required to schedule periodic background tasks in the service worker, specifically to retry syncing queued offline highlights/notes when internet connectivity is restored and to prune expired local AI response cache entries.

2. Justification for 'offscreen':
--------------------------------------------------------------------------------
The 'offscreen' permission is required to create an offscreen document for parsing HTML web page structure, performing DOM text extraction for webpage summarization, and processing background tasks that require DOM capabilities unavailable in Manifest V3 service workers.

3. Justification for 'sidePanel':
--------------------------------------------------------------------------------
The 'sidePanel' permission is required to display the extension's interactive React knowledge assistant dashboard persistently alongside the active browser tab, enabling seamless view, search, editing of notes, and management of saved highlights without leaving the web page.

4. Justification for 'storage':
--------------------------------------------------------------------------------
The 'storage' permission is required to store local user preferences, offline highlight backups, and the encrypted account authentication session token in chrome.storage.local for fast access across browser sessions.

5. Justification for 'clipboardWrite':
--------------------------------------------------------------------------------
The 'clipboardWrite' permission is required solely to allow users to click the "Copy" and "Copy to Clipboard" buttons in the extension popup and in-page AI modal to copy AI summaries and highlight text directly to their device clipboard.

6. Justification for Host permissions (api.groq.com, convex.cloud):
--------------------------------------------------------------------------------
Host permissions (api.groq.com and convex.site/cloud) are required strictly to send user-selected text to the Groq API for AI text summarization and to communicate with the Convex cloud database for syncing saved highlights across user sessions.
